# Jacobi Studio

Proyecto web editable para la resolución de sistemas de ecuaciones lineales mediante el método de Jacobi.

## Archivos
- `index.html` → estructura de la interfaz.
- `styles.css` → diseño moderno y responsive.
- `app.js` → lógica del método de Jacobi, verificación de diagonal dominante y exportación CSV.

## Cómo abrir en VS Code
1. Descomprime la carpeta.
2. Ábrela en Visual Studio Code.
3. Instala la extensión **Live Server**.
4. Haz clic derecho en `index.html`.
5. Elige **Open with Live Server**.

## Características
- Sistema editable de 2x2 hasta 6x6.
- Verificación de estricta diagonal dominante.
- Cálculo con error relativo.
- Historial de iteraciones.
- Exportación del historial a CSV.
- Ejemplos basados en la guía y en los apuntes de clase.
